十分钟规则模式演示

  1. 解压到可写目录。双击 交付中心.html，先看版本范围与当前界面。
  2. 双击 Start-LutanAI.cmd。默认从 .env.example 创建关闭模型的 .env，不会覆盖已有文件；已有服务端环境变量优先。首次安装依赖，随后构建并打开 http://127.0.0.1:8787。保留终端窗口。
  3. 打开“出钓前”，填写水域与目标，生成参考，查看数据缺口。
  4. 进入“正在作钓”。合法性保持“未知”，在上方现场助手输入“软饵试了半小时没口”。按钮会显示“先确认作钓条件”，点击会展开条件并保留草稿，不重复刷安全回复、不调用模型。
  5. 仅在真实核验允许的条件下才选择相应确认项；演示者无法核实时，停留在未知分支。已按真实情况确认且没有危险信号后，可点击“发送给现场助手”；未启用模型时仍使用规则。首次使用的实际页面验证见 修复说明。
  6. 选择明显急涨或很急水流，确认安全撤离优先于其他建议。修改输入后旧建议不应作为当前建议继续使用。
  7. 反馈“暂未尝试”或如实选择实际反馈，在“我的记录”恢复、导出与删除；不要把演示中的“有改善”当成真实用户结果。
  8. Ctrl+C 停止启动器启动的服务。已有同版本服务时启动器会提示复用；该情况需在旧终端停止旧服务，才能应用新代码或配置。

可选：自己的模型 API

首次使用可复制根目录 .env.deepseek.example 为 .env；已有 .env 时手工合并。模板默认 LLM_ENABLED=false，确认使用自己的额度后改为 true。

DeepSeek 密钥通过服务端 DEEPSEEK_API_KEY 环境变量读取，也可仅在本机 .env 的 LLM_API_KEY 填写。不要写入前端、截图、聊天记录或交付压缩包。项目未附带任何真实密钥。

LLM_ENABLED=true
LLM_PROVIDER=deepseek
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-flash
LLM_MODEL_LABEL=deepseek-flash
LLM_RESPONSE_FORMAT=json_object
LLM_TOKEN_PARAMETER=max_tokens
LLM_TIMEOUT_MS=20000
LLM_MAX_OUTPUT_TOKENS=1024
LLM_VISION_ENABLED=true
LLM_TOOLS_ENABLED=true

重启服务，运行 npm run doctor。ready 只代表配置字段完整，不能证明当前供应商可达或实际推理成功。旧服务未停时检查的是磁盘配置，现有进程仍使用启动时配置。doctor 不会发推理请求；已完成的历史真实联调见 验证记录。

通用兼容服务使用 .env.example，配置 LLM_BASE_URL、LLM_API_KEY、LLM_MODEL；只有供应商实际支持时才开启图片和工具。完整协议、超时与预算见 AI 工作流 和 V1.2 说明。

常见情况

  • 端口占用：启动器不会结束其他进程。在旧窗口 Ctrl+C，或在 .env 改 PORT=8788 后重启；开发代理仍固定使用 8787。
  • 首次安装失败：确认网络与目录写权限，然后在该目录执行 npm ci --cache .cache/npm --no-audit --no-fund。
  • 无模型输出：看来源和回退说明，再看 npm run doctor；危险、禁钓、未知合法性本来就不调用模型。
  • 城市天气失败：保留“不可用”状态，不补天气、水位或鱼情估计。没有城市不自动定位。
  • 历史记录不见：localhost、127.0.0.1、5173、8787 属于不同浏览器来源。切换前先导出；当前没有跨来源自动导入功能。
