## 已实现的闭环

在原“正在作钓”页上方新增 AI 现场助手，下方保留完整表单诊断。支持文字、可选一张图片、单项动作、依据、有效性检查、最多一个追问、实际工具事件和四类动作反馈。

```text
前端文字/压缩图片 + 脱敏会话快照
  → 输入/图片校验 → 既有风险与合法性门控
  → 视觉语言模型自行返回 tool_calls 或最终 JSON
  → 白名单工具执行 → role=tool 真实结果回填 → 最终单项建议
  → 反馈保存 → 下一轮读取本次已尝试动作 → 比较下一个变量
```

- `read_session_actions`：读取本次请求明确传入的动作、时间和反馈，不假装服务器能读 localStorage。文字“刚才没口”“我换位置了，还是没口”会被作为用户自述的尝试/反馈保留。
- `get_weather_by_city`：仅允许用户当前文字、此前用户消息或城市字段中明确出现的城市。缺少城市不猜位置，返回追问；同名城市不明确时请求补充。实际实现调用 Open-Meteo Geocoding 与 Forecast，保留来源、数据有效时刻、获取时间、时区及失败状态。
- 工具最多两轮、总计三次执行；模型最多三次请求。参数严格校验，未授权工具不执行，达到上限、超时、输出无效或模型不可用时回退已有规则。
- 原表单和 Agent 共享服务进程调用预算及并发限制，每次物理模型请求都会计数，不重试。DeepSeek 非思考模式用于该循环，不保存或回填模型思考原文。

## 图像、事实与安全边界

客户端仅接受 JPG/PNG/WebP，原文件不超过 20 MB，浏览器缩放最长边至 1280 px 并重新编码 JPEG，去掉原文件元数据。压缩后不超过 2 MB。服务端检查 MIME、实际文件头、base64 与解码大小，不接受远程图片 URL。

图片仅随当前推理请求临时在内存中使用，不写入本机记录、日志或服务器文件。会话只保留 `had_image` 和模型整理的观察，不保留原图。

照片观察、用户描述和未知项分别展示。照片不能确认涨退水趋势、鱼种出现、鱼口、河段许可或水位实测。用户说“感觉在退水”只能记作用户观察。真实联调后，跟饵、疑似触碰、充分尝试无口三类分支的动作、依据和检查限定为规则候选，越界即回退；已有失败反馈不能强制重复。其他普通分支保留受限生成，仍需进一步验收，不声称完全消除幻觉。

危险水情、用户报告禁钓或合法性未知均在模型调用前拦截。自由文字中的急流、急涨或明确禁钓也会触发门控，不依赖图片来放行。规则与模型结果均不构成安全或垂钓许可保证。

## 本机记录与恢复

原 `lutan_records_v1` / V2 表单记录保持原结构和功能。新增 `lutan_agent_sessions_v1` 保存最多 20 个轻量会话，每个会话最多 20 条消息、20 条动作、30 条工具事件和最近结果。所有快照都经过 Schema 校验。

刷新现场页会恢复最近会话及其上下文；“我的记录”增加现场会话列表，可恢复、导出、删除、单独清空。新建会话为显式按钮。读取损坏记录不覆盖原文，存储拒绝时提示导出。精确坐标和链接在发送文字时做基础移除，不公开钓点，不提供云端同步。

## 配置与使用

沿用 V1.1 `.env`，推荐：

```dotenv
LLM_ENABLED=true
LLM_PROVIDER=deepseek
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-flash
LLM_MODEL_LABEL=deepseek-flash
LLM_RESPONSE_FORMAT=json_object
LLM_TOKEN_PARAMETER=max_tokens
LLM_TIMEOUT_MS=20000
LLM_MAX_OUTPUT_TOKENS=1024
LLM_VISION_ENABLED=true
LLM_TOOLS_ENABLED=true
```

密钥沿用环境变量 `DEEPSEEK_API_KEY`，或仅在服务端 `LLM_API_KEY` 配置。DeepSeek 模式只接受官方 API 主机或本机回环代理地址，避免将其密钥误发至示例中的其他供应商地址。通用兼容供应商仍可使用 `LLM_PROVIDER=openai_compatible`，是否支持图片/工具由显式开关确认；不支持时给出提示或规则降级。

默认 DeepSeek 单次请求超时 20 秒，服务端可配置上限 60 秒；Agent 整轮上限 60 秒，客户端等待上限 65 秒。用户可取消请求。`deepseek-v4-pro` 不作为图片模型，模型名/能力开关不等于已经真实联调成功。

启动 `npm run dev`，打开 [http://127.0.0.1:5173/#diagnose](http://127.0.0.1:5173/#diagnose)。按实际情况设置“作钓条件与安全确认”，只有真实核对允许后才选择相应选项。

1. 图文：输入“小河道钓鳜鱼，软饵试了半小时没口，感觉在退水”，可附真实现场照片，发送后核对照片观察与用户描述。
2. 记忆：点击“没改善”，再发送“刚才建议的动作试了20分钟，还是没口”，查看实际的会话工具事件和不同的下一步。
3. 天气：明确填写城市“南充”或在文字中说明城市并请求天气，查看工具数据来源与时刻。没有城市时不能自动定位。
4. 降级：设置 `LLM_ENABLED=false` 并重启后，继续发送可得到规则结果；原有表单和记录可用。

Open-Meteo 公共服务用于本项目的个人、非商业本机演示，缓存城市查询 15 分钟并显示 Open-Meteo / GeoNames 与 CC BY 4.0 署名。城市天气是网格模型数据，不是钓点实测、水温、河道水位或鱼情。公开商业使用前需确认适用服务计划和条款；失败不补估计值。
